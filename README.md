# Portfolio

## Run locally

**Option A — open the file (no install):**

Double-click `index.html`, or in PowerShell:

```powershell
cd E:\Murad_Portfolio\Portfolio
start index.html
```

**Option B — local server (recommended):**

Node.js is required. From this folder:

```powershell
npm start
```

Then open: **http://localhost:3000**

(`python -m http.server` will not work unless Python is installed on your PC.)
